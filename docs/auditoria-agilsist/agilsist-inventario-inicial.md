# Inventario inicial do Agilsist

Levantamento realizado em 15/06/2026 no sistema de producao
`https://projov.agilsist.com.br/`, sem executar operacoes de escrita.

As credenciais utilizadas na auditoria nao sao registradas neste documento.

## Login

O login do Agilsist permite selecionar quatro perfis:

- Usuario Interno
- Aprendiz
- Educador/Funcionario
- Parceiro

Tambem existem os fluxos `Deseja alterar sua senha?` e
`Esqueceu sua senha?`. Esses fluxos nao foram acionados.

## Limitacoes desta etapa

Este inventario comprova a existencia dos menus para os perfis acessados. Ele
nao comprova, por si so, que cada funcao esta operacional nem que o ProSis
reproduz todos os campos, filtros, regras e resultados do Agilsist.
